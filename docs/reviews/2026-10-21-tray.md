# Optional tray behavior — blocker #4

Requested report date: 2026-10-21. Implementation/validation run: 2026-10-22.
Scope: Windows 10/11 and Linux; macOS remains outside public launch.

Implemented native Tauri tray menus, Show/focus and single-instance reveal,
default-OFF Settings toggle, immediate vault lock before hiding, shared guarded
Close/Quit/exit, and Linux fallback. Main files: `src-tauri/src/tray.rs`, `lib.rs`,
`state.rs`, settings repository/service/command/DTO, migration `0006`,
`src/features/settings/*`, bridge types/commands, `src/lib/nativeVaultEvents.ts`,
`src/bridge/invoke.ts`, `src/app/App.tsx`, both translation catalogs and the
narrow main event permissions/generated capability metadata. Existing settings fixtures were extended.

Decisions:

- The existing settings store is a fixed singleton row, not key/value. Add only
  immutable migration `0006_keep_running_in_tray.sql`; 0/1, NOT NULL, default 0.
- Always lock immediately on hide, even with auto-lock configured, because
  hidden renderer timers can throttle. Call the existing native lock service,
  then emit a session boundary to clear renderer data and reject late IPC.
- Quit refuses rather than defers when the existing operation gate is busy.
  Bring the window forward and show static localized refusal text; retry after
  completion. Successful exit closes new operation admission before Tauri exit.
- Tray Lock now also takes the gate to prevent a concurrent unlock from
  reopening a just-locked session; busy work must finish before retrying.
  Successful locking calls the existing lock service.
- Settings stay encrypted. First locked launch uses OFF/Arabic until unlock;
  runtime preference/menu locale survive subsequent locks. No plaintext cache.
- Linux requires a registered StatusNotifier host and a usable indicator
  library. Creation failure logs `TRAY_UNAVAILABLE` only; the toggle disables
  and Close quits. A native host-loss monitor reveals the locked window.
  Restart after enabling/re-enabling support; no automatic tray recreation.
- Use only Tauri's `tray-icon` feature on Windows/Linux. Direct Linux GIO and
  libloading declarations reuse already-locked GTK stack packages for local
  bus detection/library preflight. No network, shell, cloud or renderer OS
  access is added. Binary-size impact has not been measured.
- Persist size/position but exclude visibility, so quitting while hidden never
  makes a later launch depend on tray availability.

KDE checks are unperformed. Packaging/library resolution, tray presentation,

suite or canonical/container visual command is run. No public-launch sign-off
is implied.
