## Decisions

1. Installation export means all domain records/relationships, including archived
   and unlinked office/client records. Settings/profile, security material,
   derived/local history and `pending_file_deletions` are excluded. Only referenced
   managed files are copied; missing/damaged/unsafe files abort the whole export.
2. Case scope includes its direct work/finance, linked clients, current or newest
   archived fallback POAs (same view as the UI), scoped links/lawyers and owned
   documents. Other cases and client-only/office tasks/expenses are excluded.
   Cross-case previous-hearing IDs become null only in the export. Shared
   client/POA documents are included whole, as the warning explains.
3. Exports are plaintext disclosures, cannot restore the app and require warning
   confirmation before the picker. Destinations inside the vault, including
   symlink aliases, are refused. Lock invalidates work/reveal capabilities but
   cannot retract an export already published. External exports survive deletion.
4. CSV uses BOM UTF-8, CRLF, integer EGP minor units, unchanged ISO date-only values
   and a documented reversible spreadsheet-formula guard. No formatted money
   column/importer was added. Manifest hashes exact CSV/document bytes; CSV counts
   exclude headers, document counts are null, and the manifest excludes itself.
5. Existing minute-level names are refused, including publication races. Unsafe
   internal-number characters use reversible UTF-8 `~HH` encoding; overlong names
   fail safely. Linux uses `renameat2(RENAME_NOREPLACE)`, Windows directory rename.
   Unix output modes are 0700/0600; Windows inherits the parent's ACL. Ordinary
   errors attempt cleanup; crashes or cleanup refusal may leave `.partial` data.

## Unresolved risks

- Physical Windows/Linux picker/reveal, Excel Arabic/import behavior, Windows
  ACL/sharing/rename, removable/network filesystems, long paths and power-loss
  acceptance remain unverified. No Windows build or desktop suite ran.
- Shared client/POA documents may contain information beyond the case; contents
  are not redacted. External exports and crash-left partial folders contain
  confidential plaintext under the user's control. Secure erasure is not promised.
- Unsupported no-replacement filesystems fail safely. Post-publication directory
  sync is best effort; the existing helper has no Windows directory flush.
  Cleanup can fail if permissions/storage fail. Public-launch readiness is not
  certified; the support bundle (blocker #3 part 3) and other launch gates remain.
