# LegalMaster Solo v0.2.3 — Beta

## English

This beta updates backup navigation and makes client, case and finance list rows easier to open.

- Updates the Zod validation dependency to address a high-severity memory exhaustion advisory.
- Backup controls are available under Settings → Backups.
- Click a client or case row to open its details, or a finance row to inspect the entry. Existing links and action buttons remain available.

Windows 10/11 x64 and Linux x64 packages are included; macOS is not included. Windows executables and Linux packages are unsigned. Verify the supplied SHA-256 checksums. Exports are unencrypted and can contain sensitive data.

This draft is for evaluation. Physical Windows and Linux acceptance, package installation checks, cross-device restore, and privacy/legal review remain open. Keep a separate backup of important data.

## العربية

يحدّث هذا الإصدار التجريبي الوصول إلى النسخ الاحتياطي ويجعل فتح صفوف العملاء والقضايا والمعاملات المالية أسهل.

- تحديث مكتبة التحقق Zod لمعالجة ثغرة عالية الخطورة قد تستنزف الذاكرة.
- تتوفر أدوات النسخ الاحتياطي ضمن الإعدادات ← النسخ الاحتياطي.
- اضغط على صف العميل أو القضية لفتح التفاصيل، أو على صف المعاملة المالية لعرضها. تظل الروابط وأزرار الإجراءات متاحة.

يتضمن الإصدار حزم Windows 10/11 وLinux بمعمارية x64، ولا يشمل macOS. ملفات Windows وحزم Linux غير موقّعة. تحقّق من قيم SHA-256 المرفقة. ملفات التصدير غير مشفّرة وقد تحتوي على بيانات حساسة.

هذه المسودة للتقييم. لا تزال الاختبارات العملية على Windows وLinux، وفحوصات تثبيت الحزم، والاستعادة بين الأجهزة، ومراجعة الخصوصية والشؤون القانونية قيد الانتظار. احتفظ بنسخة احتياطية منفصلة من بياناتك المهمة.
