# LegalMaster Solo v0.2.0 — Public beta

## English

LegalMaster Solo is an offline-first desktop app for individual Egyptian lawyers. This public beta is for evaluation; keep a separate backup of important data.

### Downloads and supported platforms

- Windows 10 and Windows 11, x64: NSIS installer and portable ZIP.
- Linux x64: Debian `.deb`, RPM `.rpm`, and AppImage.
- macOS is not included in this release.

### Installation

On Windows, run the installer or extract the portable ZIP and launch the application. The portable ZIP does not move the app's data folder; application data remains in its normal Windows location. Both Windows executables are currently unsigned, so Windows may display a SmartScreen or unknown-publisher warning. This is expected under the current signing policy.

On Linux, install the `.deb` or `.rpm` using the appropriate package manager. For AppImage, mark the downloaded file executable before launching it. Linux packages are unsigned. Verify the published SHA-256 checksums; checksums help detect file changes but are not a code signature.

### Privacy

The app works locally and does not include telemetry or automatic data upload. Support bundles are saved only when you choose a location. Exports are unencrypted files and may contain sensitive legal and personal information; store and share them carefully.

### Known limitations

This is a beta, not ready for public launch. Although automated Linux checks pass, physical GNOME tray checks (with and without AppIndicator), KDE tray checks, and Linux package installation, update and removal checks remain. Physical Windows 10/11 checks also remain. Visual baselines need owner approval. Windows artifacts are unsigned, and Linux packages are unsigned. Cross-device and repeated restore acceptance, privacy/legal review, a published privacy notice and terms, and user guides remain pending. macOS and automatic updates are not included.

## العربية

LegalMaster Solo تطبيق سطح مكتب يعمل دون اتصال بالإنترنت، ومخصص للمحامين المصريين الأفراد. هذا إصدار تجريبي عام للتقييم؛ احتفظ بنسخة احتياطية منفصلة من بياناتك المهمة.

### التنزيلات والمنصات المدعومة

- Windows 10 وWindows 11 بمعمارية x64: مُثبّت NSIS وملف ZIP محمول.
- Linux بمعمارية x64: حزم Debian بصيغة `.deb` وRPM بصيغة `.rpm` وAppImage.
- هذا الإصدار لا يشمل macOS.

### التثبيت

في Windows، شغّل المُثبّت أو فك ضغط ملف ZIP المحمول ثم شغّل التطبيق. لا ينقل ملف ZIP مجلد بيانات التطبيق؛ تظل البيانات في موقعها المعتاد في Windows. ملفات Windows التنفيذية غير موقّعة حاليًا، لذلك قد يعرض Windows تحذير SmartScreen أو تحذير ناشر غير معروف. هذا متوقع وفق سياسة التوقيع الحالية.

في Linux، ثبّت حزمة `.deb` أو `.rpm` باستخدام مدير الحزم المناسب. لتشغيل AppImage، اجعل الملف الذي نزّلته قابلًا للتنفيذ أولًا. حزم Linux غير موقّعة. تحقّق من قيم SHA-256 المنشورة؛ فهي تساعد على كشف تغيّر الملفات لكنها لا تُعد توقيعًا برمجيًا.

### الخصوصية

يعمل التطبيق محليًا ولا يتضمن قياسًا عن بُعد أو رفعًا تلقائيًا للبيانات. لا تُحفظ حزمة الدعم إلا بعد اختيارك لموقع الحفظ. ملفات التصدير غير مشفّرة وقد تحتوي على معلومات قانونية وشخصية حساسة؛ احفظها وشاركها بحذر.

### القيود المعروفة

هذا إصدار تجريبي وغير جاهز للإطلاق العام. رغم اجتياز الفحوصات الآلية في Linux، لا تزال اختبارات شريط النظام العملية في GNOME (مع AppIndicator وبدونه) وKDE، واختبارات تثبيت حزم Linux وتحديثها وإزالتها، قيد الانتظار. كما لم تكتمل الفحوصات العملية على Windows 10/11. تحتاج لقطات الواجهة إلى اعتماد المالك. ملفات Windows وحزم Linux غير موقّعة. كما لم يكتمل اعتماد الاستعادة بين الأجهزة وتكرارها، والمراجعة القانونية والخصوصية، ونشر إشعار الخصوصية والشروط، وأدلة الاستخدام. لا يشمل الإصدار macOS أو التحديثات التلقائية.
