# Legal Masr v0.2.4 — Beta

## English

This beta includes the SQLite security fix and Windows/Linux packaging fixes.

- Updates rusqlite and builds SQLCipher 4.20.0 with SQLite 3.54.1 to address RUSTSEC-2026-0459 / CVE-2026-119375.
- Preserves encrypted databases, backup/restore, unsigned count reads and CSV export headers after the dependency upgrade.
- Adds regression checks for the actual linked database engine, encrypted WAL writes, backup/reopen and wrong-key rejection.
- Includes packaging download retries and the normalized Linux AppImage runtime.
- Retains the Settings → Backups navigation and client, case and finance row navigation from v0.2.3.

### Downloads

Windows 10/11 x64: use the setup `.exe` installer or the portable `.zip`.
Linux x64: use the `.deb`, `.rpm` or `.AppImage` for your system.
Extract the portable ZIP before launching. Make the AppImage executable before launching.
The portable ZIP and AppImage keep application data in the normal operating-system data directory.
Verify downloads against the attached `SHA256SUMS.txt`.

### Beta limitations

Windows executables and Linux packages are unsigned. Windows may show a SmartScreen or unknown-publisher warning. macOS is not included.
Physical Windows/Linux installation, update/removal, desktop tray behavior, cross-device restore and privacy/legal acceptance remain unverified. This release is for beta evaluation and does not certify those checks. Keep a separate backup of important data. Exports are unencrypted and may contain sensitive data.

## العربية

يتضمن هذا الإصدار التجريبي إصلاح ثغرة SQLite وتحسينات بناء حزم Windows وLinux.

- تحديث rusqlite واستخدام SQLCipher 4.20.0 مع SQLite 3.54.1 لمعالجة الثغرة RUSTSEC-2026-0459 / CVE-2026-119375.
- الحفاظ على تشفير قواعد البيانات والنسخ الاحتياطي والاستعادة وقراءة الأعداد غير السالبة وعناوين أعمدة CSV بعد التحديث.
- إضافة اختبارات لمحرك قاعدة البيانات المستخدم فعليًا والكتابة المشفّرة في وضع WAL وإعادة فتح النسخ الاحتياطية ورفض المفتاح الخاطئ.
- تحسين إعادة محاولة تنزيل أدوات بناء الحزم وتهيئة تشغيل AppImage على Linux.
- الاحتفاظ بالوصول إلى النسخ الاحتياطي من الإعدادات وفتح صفوف العملاء والقضايا والمعاملات المالية كما في الإصدار v0.2.3.

### التنزيل

Windows 10/11 بمعمارية x64: استخدم ملف التثبيت `.exe` أو الأرشيف المحمول `.zip`.
Linux بمعمارية x64: اختر حزمة `.deb` أو `.rpm` أو `.AppImage` المناسبة لنظامك.
فك ضغط ZIP قبل التشغيل، واجعل ملف AppImage قابلاً للتنفيذ قبل تشغيله.
تظل بيانات التطبيق في مجلد البيانات المعتاد لنظام التشغيل عند استخدام ZIP المحمول أو AppImage.
تحقّق من التنزيلات باستخدام ملف `SHA256SUMS.txt` المرفق.

### حدود الإصدار التجريبي

ملفات Windows وحزم Linux غير موقّعة، وقد يعرض Windows تحذير SmartScreen أو ناشر غير معروف. لا يتضمن الإصدار macOS.
لم تُستكمل بعد الاختبارات العملية للتثبيت والتحديث والإزالة وسلوك أيقونة النظام على Windows وLinux، والاستعادة بين الأجهزة، واعتماد الخصوصية والشؤون القانونية. هذا الإصدار للتقييم التجريبي ولا يؤكد اجتياز تلك الفحوصات. احتفظ بنسخة احتياطية منفصلة من بياناتك المهمة. ملفات التصدير غير مشفّرة وقد تحتوي على بيانات حساسة.
