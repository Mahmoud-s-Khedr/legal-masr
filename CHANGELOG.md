# Changelog

## 0.2.0 — Public beta

### English

- Permanently delete archived clients, archived cases, or all vault data through a guided flow with one final confirmation.
- Export case data or the full installation to ordinary, unencrypted files. Review the warning before saving and protect exported files yourself.
- Create a redacted support bundle locally. Review what it contains; nothing is sent automatically.
- Optionally keep the app in the system tray. This setting starts off; hiding the window locks it.
- Correct data refresh and clearing behavior after changes to clients, cases, and vault state.
- Upgrade ZIP handling used by encrypted backups and add checks against unsafe archive entries.
- Improve the Windows desktop CI harness so it waits for the app and native dialogs more reliably.

### العربية

- حذف العملاء المؤرشفين أو القضايا المؤرشفة أو جميع بيانات الخزنة نهائيًا عبر خطوات إرشادية وتأكيد نهائي واحد.
- تصدير بيانات قضية أو بيانات التطبيق كاملة إلى ملفات عادية غير مشفّرة. راجع التحذير قبل الحفظ واحمِ الملفات المُصدّرة بنفسك.
- إنشاء حزمة دعم منقّحة محليًا. راجع محتوياتها؛ لا تُرسل أي بيانات تلقائيًا.
- تشغيل التطبيق اختياريًا في شريط النظام. يكون الخيار متوقفًا افتراضيًا، ويؤدي إخفاء النافذة إلى قفل التطبيق.
- إصلاح تحديث البيانات ومسحها بعد تغييرات العملاء والقضايا وحالة الخزنة.
- ترقية معالجة ملفات ZIP المستخدمة في النسخ الاحتياطية المشفّرة وإضافة فحوصات للملفات غير الآمنة داخل الأرشيف.
- تحسين اختبارات سطح المكتب في Windows لتنتظر التطبيق والنوافذ الأصلية بصورة أكثر موثوقية.
